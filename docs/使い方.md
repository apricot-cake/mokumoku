# 使い方

mokumoku は、読み込み済みの動画を、同じチャンネルの基準となる再生数に対する倍率で並べます。ここでは、動画の読み込み方と倍率の計算方法を説明します。

必要な環境とインストール手順は、[README](../README.md#インストール)を参照してください。

## 動画を確認する

1. YouTube チャンネルの「動画」タブを「新しい順」で開きます。
2. Chrome のツールバーで mokumoku のアイコンを押します。
3. サイドパネルで、倍率と動画一覧を確認します。

「人気順」や「古い順」では倍率を計算しません。読み込まれる動画に偏りが出るためです。

## 動画を追加で読み込む

「読み込み範囲」で「直近1か月」などを選ぶと、その期間より古い動画が現れるまで自動で読み込みます。選んだ期間より古い動画は、パネルの一覧には表示しません。

一度に読み込みすぎないよう、1回の操作で追加した動画が500本以上になると、次の読み込みを止めます。

「手動」を選んだ場合は、自動では読み込みません。ヘッダーの「さらに読み込む」を押すと、1回分ずつ追加できます。

## パネルの開閉

パネルは、開いたときのタブとチャンネルに対応しています。同じウィンドウで別のタブに切り替えたり、別のページに移動したりすると閉じます。同じチャンネル内の移動では閉じません。たとえば、チャンネルの「ホーム」から「動画」タブへ移動しても、パネルは開いたままです。

## 倍率の求め方

公開からの経過時間が同じくらいの動画と比べて、どれだけ多く見られているかを倍率で示します。読み込み済みの動画から基準となる再生数を推定し、実際の再生数をその基準で割って計算します。

たとえば2倍なら、基準に対して約2倍の再生数があります。特定の期間内に増えた再生数を測っているわけではなく、一覧に表示されている現在の再生数と経過時間から推定した値です。

### 基準に使う動画

- 公開から1日以上たった動画を、新しい順に最大200本使います。
- 動画が8本未満の場合は、倍率を表示しません。
- 経過日数の幅が狭すぎる場合も表示しません。最も古い動画と最も新しい動画の経過日数には、3倍以上の差が必要です。
- 「読み込み範囲」で選んだ期間に関係なく、読み込み済みの動画を基準に使います。

公開から1日未満の動画は値が変わりやすいため、基準には含めません。パネルでは、順位とは別の欄に参考値として表示します。

### 計算方法

大きく伸びた数本の動画に基準が引っ張られにくい、Theil–Sen 推定という方法を使います。読み込み済みの動画に、次の式を当てはめます。

```text
log(再生数) = a + b × log(経過日数)
```

古い動画ほど再生数が少ないチャンネルでも、経過日数が長いほど基準が下がらないよう、傾き `b` は0以上に制限します。傾きが0の場合は、経過時間による補正を行いません。
