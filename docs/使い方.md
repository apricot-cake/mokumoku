# 使い方

YouTube チャンネルの「動画」タブで、読み込み済みの動画を「同じ経過時間での通常の再生数」に対する倍率で並べ、サイドパネルに表示する Chrome 拡張機能です。公開から日が浅いのに伸びている動画を見つけるために使います。

## 動画を確認する

Chrome 142 以降に対応しています。YouTube チャンネルの「動画」タブを「新しい順」で開き、ツールバーの mokumoku のアイコンを押すと、比較結果がサイドパネルに表示されます。

## 倍率の求め方

一覧から読めるのは、各動画の現在の累積再生数と経過時間だけです。読み込み済みの動画から `log(再生数) = a + b·log(経過日数)` を Theil–Sen 推定で当てはめ、その期待値に対する実際の再生数の比を倍率とします。

- 公開から1日未満の動画は値のぶれが大きいので、基準に入れず、順位とは別の欄に参考値として並べます。
- 基準は公開から1日以上たった動画を新しい順に最大200本使い、8本未満なら出しません。
- 古い動画ほど再生数が少ないチャンネルでは傾きを 0 で止めます。このときの倍率は、経過時間を考慮しない中央値との比になります。
- 並び順が「新しい順」のときだけ計算します。人気順や古い順では、読み込まれる動画が偏るためです。
- パネルの「読み込み範囲」で「直近1か月」などを選ぶと、範囲を超える動画が現れるまで自動で続けて読み込み、範囲より古い動画は一覧から隠します。1回で増やすのは500本までです。倍率の基準には、範囲に関係なく読み込み済みの動画を使います。
- パネルは開いたタブ専用です。同じウィンドウで別のタブに切り替えたときや、別のページへ移ったときは閉じます。同じチャンネル内の移動（「ホーム」から「動画」タブへなど）では閉じません。
- 「手動」のときは自動では読み込まず、ヘッダーの「さらに読み込む」で1回分ずつ読み込みます。
