# mokumoku

mokumoku は、同じ YouTube チャンネルの中で、普段より多く見られている動画を探す Chrome 拡張機能です。公開からの経過時間を考慮して再生数を比較し、結果を閲覧中のページの横に表示します。

[操作デモ](https://apricot-cake.github.io/mokumoku/)では、インストールせずに、架空の動画を使って期間の選択や追加読み込みを試せます。

## 主な機能

- 同じチャンネルの動画を、基準となる再生数に対する倍率で比較できます。
- 「直近1か月」などの期間を選び、対象の動画をまとめて読み込めます。
- 「さらに読み込む」で、動画を1回分ずつ追加できます。
- 日本語と英語で表示できます。

YouTube チャンネルの「動画」タブを「新しい順」で開いた場合に対応します。倍率の基準は、読み込み済みの動画の再生数と経過時間から推定します。計算方法と条件は[使い方](docs/使い方.md#倍率の求め方)を参照してください。

## インストール

Chrome 142 以降が必要です。ソースからインストールするには、Node.js 24.12.0 以降と pnpm 12.11.2 も用意してください。

```powershell
git clone https://github.com/apricot-cake/mokumoku.git
cd mokumoku
pnpm install --frozen-lockfile
pnpm run build
```

ビルドが終わったら、Chrome で `chrome://extensions` を開き、デベロッパーモードを有効にします。「パッケージ化されていない拡張機能を読み込む」から、リポジトリ内の `.output/chrome-mv3` フォルダーを選んでください。

更新するときは、新しいソースを取得して `pnpm run build` を実行し、拡張機能の管理画面で mokumoku を再読み込みしてください。

## 使い方

1. YouTube チャンネルの「動画」タブを「新しい順」で開きます。
2. Chrome のツールバーで mokumoku のアイコンを押します。
3. サイドパネルで倍率と動画一覧を確認します。期間を指定して読み込むときは、「読み込み範囲」を選びます。

公開から1日未満の動画は、参考値として別の欄に表示します。基準に使える動画が8本未満の場合など、比較に必要な条件がそろわないときは倍率を表示しません。

パネルは、開いたときのタブとチャンネルに対応しています。同じウィンドウで別のタブに切り替えたり、別のページに移動したりすると閉じます。同じチャンネル内の移動では開いたままになります。
