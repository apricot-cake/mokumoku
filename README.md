# mokumoku

mokumoku は、同じ YouTube チャンネルの中で、普段より多く見られている動画を探す Chrome 拡張機能です。公開からの経過時間を考慮して再生数を比較し、結果を閲覧中のページの横に表示します。

## 主な機能

- 同じチャンネルの動画を、基準となる再生数に対する倍率で比較できます。
- 「直近1か月」などの期間を選び、対象の動画をまとめて読み込めます。
- 日本語と英語で表示できます。

YouTube チャンネルの「動画」または「ライブ」タブを「新しい順」で開いた場合に対応します。配信中・配信予定の動画は対象外です。

## インストール

[Chrome ウェブストア](https://chromewebstore.google.com/detail/hmhgbppkbadnofkbnnbmolgccnpmnfoe)からインストールできます。Chrome 142 以降が必要です。

バージョンごとの変更内容は [Releases](https://github.com/apricot-cake/mokumoku/releases) を参照してください。

## 開発者向け

開発環境の準備、テスト、画面の確認方法は[開発ガイド](docs/CONTRIBUTING.md)を参照してください。

不具合の報告や改善の提案は [Issues](https://github.com/apricot-cake/mokumoku/issues) で受け付けています。投稿は公開されるため、個人情報や公開したくない閲覧情報を含めないでください。

脆弱性は[非公開フォーム](https://github.com/apricot-cake/mokumoku/security/advisories/new)から報告してください。
