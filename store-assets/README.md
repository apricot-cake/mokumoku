# ストア提出用画像

| ファイル | 内容 |
| --- | --- |
| `screenshot-ja.png` | 1280×800の画面例。見出しと使い方の横に、実際のサイドパネルを大きく配置しています |
| `promo-small.png` | 440×280のプロモーション画像。採用したアイコンと短い紹介文を使っています |
| `capture.json` | 撮影先、撮影日時、チャンネル、表示件数の記録です |
| `package-report.json` | 提出用 ZIP の検査結果と、ファイルを識別する SHA-256 の値です |

画面は、開発専用の Chrome をウィンドウを表示しないヘッドレスモードで起動して撮影しました。ページへのサンプル追加、動画の再生、評価、コメント、チャンネル登録は行っていません。

サイドパネルは横幅480px、2倍の解像度で撮影し、縦横比を保って横幅704pxで配置しています。一覧の下部は枠に合わせて切り抜いていますが、タイトル、再生数、倍率などの内容は加工していません。

左側には、38pxの見出しと22pxの説明、操作の流れを配置しています。画像内のブラウザ枠と3つの手順は説明用の装飾で、Chrome 自体を撮影したものではありません。

提出前には、最新のソースと ZIP の対応を確認してください。掲載文や画像に未コミットの変更がある場合は、その状態を検査結果に記録します。
