# ストア提出用画像

- `screenshot-ja.png`: 1280×800。見出しと使い方の横に、実際のサイドパネルを大きく配置した画面例。
- `promo-small.png`: 440×280。採用したアイコンと短い紹介文。
- `capture.json`: 撮影先、撮影日時、チャンネル、表示件数。
- `package-report.json`: 提出用 ZIP の内容検査と SHA-256。

画面は開発専用のヘッドレス Chrome で撮影した。
ページへのサンプル追加、動画の再生、評価、コメント、登録操作は行っていない。
サイドパネルは横幅480px・2倍の解像度で撮影し、縦横比を保って横幅704pxで配置した。
一覧の下部は枠内で切り抜き、動画タイトルや倍率を読みやすくした。
見出しは38px、説明は22pxで、操作の流れとともに左側へ配置した。
画像内のブラウザ枠と3つの手順は説明用の装飾で、Chrome 自体を撮影したものではない。
タイトル、再生数、倍率など、撮影した画面内の内容は加工していない。

ZIP は現在の実行コードとアイコンから作成した候補。
掲載文・画像などの未コミット状態は、検査結果の記録で区別する。
提出直前に、最新の実行コードと ZIP の対応を確認する。
