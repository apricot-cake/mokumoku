# アプリアイコン

Creative Production と ImageGen で作成した、赤い雲のアイコンです。2026年10月22日に採用し、翌23日に ImageGen で輪郭を約1.5倍の太さに調整しました。

`source.png` は、背景の透過処理で残った孤立した点を取り除き、赤色を `#FF0033` に統一した原稿です。

配布用の PNG は `public/icon/` に保存しています。雲の輪郭を切り出し、縦横比を保ったまま、各サイズの中央に配置しています。128px 版は絵柄の幅を96pxとし、小さいサイズでは輪郭が読めるよう余白を減らしています。

各ファイルの寸法と絵柄の幅は、`exports.json` に記録しています。
