# アプリアイコン

Creative Production と ImageGen で作成した赤い雲の太線アイコン。
2026-10-22 に採用。2026-10-23 に ImageGen で輪郭を約1.5倍に太くした。
`source.png` は透過部分の孤立した点を除き、赤色を統一した原稿。

配布用 PNG は `public/icon/` に保存する。
書き出し時に透過処理の孤立した点を除き、色を `#FF0033` に統一した。
雲の輪郭を切り出し、縦横比を保って各サイズの中央へ配置した。
128px 版は絵柄の幅を96pxにし、小さい版は輪郭が読めるよう余白を減らした。
各ファイルの寸法と絵柄の幅は `exports.json` に記録する。
